# Portfolio source

Static portfolio for Guda Sriram, copied from the approved ChatGPT Sites design.

## Files

- `index.html`: page content and layout
- `style.css`: responsive styling
- `script.js`: character-by-character name animation
- `assets/`: referenced portraits and certification images

## Preview locally

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

No package installation or build step is required. Google Fonts is loaded externally, with local fallback fonts configured.

## Hosting

This copy does not change current Sites hosting or configure GitHub Pages. The files are at the repository root for static hosting. Preserve relative asset paths.

The résumé PDF and its download links are omitted pending explicit approval to publish that document in this public repository. The existing Sites version is unchanged.
